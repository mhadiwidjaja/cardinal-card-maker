# Changelog

## [0.1.0]

The first release of Cardinal.

- Card templates with a visual layer editor, show-if rules and front and back faces.
- A card spreadsheet with live preview, Excel/CSV/XLSX import and export, icons and keywords.
- Statistics: counts and histograms by any field, with filters.
- A playtest table for 1 to 4 players, deck building, draw odds and a gallery page for playtester ratings.
- Print-ready PDFs with bleed, crop marks and CMYK output, a print check, a cost planner and a test print.
- Downloads for Windows, Mac (Apple silicon) and Linux, each as a windowed app and a browser version.
